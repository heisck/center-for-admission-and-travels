DESIGN DECISIONS MADE

Decision 1: No Component Duplication
  Rationale: Maintains visual parity automatically
  Implementation: Reuse components, change data only

Decision 2: No Database/Backend
  Rationale: Simpler, faster to implement
  Implementation: React Context + localStorage

Decision 3: Exact Page Clones (No Sidebars)
  Rationale: Prevents "AI dashboard" aesthetic
  Implementation: Edit controls appear on hover

Decision 4: Route Groups for Auth
  Rationale: Clean routing, easy to extend
  Implementation: /admin/(authenticated) group

Decision 5: Page-Level History Tracking
  Rationale: Simpler than component-level
  Implementation: Each page has version array
