## Button Guide

| Button | Action |
|--------|--------|
| ↶ Undo | Revert last change |
| ↷ Redo | Restore previous change |
| ↻ Reset | Restore all defaults |
| ⬇️ Export | Save backup as JSON |
| ⬆️ Import | Load from JSON file |
| 👁️ Preview | Toggle live preview (mobile) |
| ➕ Add | Create new item |
| 🗑️ Delete | Remove item |
| ✏️ Edit | Inline text editing (auto) |

## Pro Tips

1. **Live Preview (Desktop)**
   - Right side shows how changes look in real-time
   - No need to refresh the page

2. **Undo/Redo**
   - Unlimited history
   - Use freely without worry
   - Can revert all the way to start

3. **Backup Your Work**
   - Click Export regularly
   - Save JSON file as backup
   - Can import anytime to restore

4. **Images**
   - Paste image URLs directly
   - Supports: JPG, PNG, WebP
   - Preview shows before saving

5. **Mobile Friendly**
   - Toggle preview button to edit
   - Full interface works on tablets
   - Stack layout optimizes on small screens

6. **Content Organization**
   - Expand sections to see details
   - Collapse when done
   - Reduces clutter

## Common Tasks

### Add a New Package
1. Go to "Packages" tab
2. Click "➕ Add Package" button
3. Enter name, price, duration, highlights
4. Upload image
5. Click save/confirm

### Edit Team Member
1. Go to "About" tab
2. Find team member card
3. Click to expand
4. Edit name, role, description
5. Change photo via image editor

### Change Package Price
1. Go to "Packages" or "Travel Tours" tab
2. Click expand button for package
3. Scroll to price field
4. Update number
5. Auto-saves

### Add Core Value
1. Go to "About" tab
2. Scroll to "Core Values"
3. Click "➕ Add Value" button
4. Enter title and description
5. Done!

## Troubleshooting

**Changes not showing?**
- Make sure you clicked save (green checkmark)
- Check if preview is toggled correctly

**Lost my changes?**
- Click Undo (↶) to restore
- Or click Reset to go back to start

**Can't upload image?**
- Paste image URL instead
- Format: /images/filename.jpg

**Want to restore old version?**
- Click "Export" to see history
- Or click "Reset" to start fresh

## Data Backup

### How to Backup
1. Click the Export button (⬇️)
2. Save the `.json` file safely
3. Keep multiple copies

### How to Restore
1. Click the Import button (⬆️)
2. Select previously saved `.json` file
3. Click load
4. All data restored!
