# Get Started With Your Admin Dashboard - Right Now!

## Step 1: Open the Admin Panel
```
URL: http://localhost:3000/admin
```

That's it! You're in.

---

## Step 2: You'll See 5 Tabs
```
[Home] [About] [Packages] [Travel Tours] [Services]
```

Choose any tab to edit that section of your website.

---

## Step 3: Start Editing

### To Edit Text
1. Click any text in the editor
2. It becomes an input field
3. Type your new text
4. Press Enter or click ✅ to save
5. Changes appear instantly

**Example**: Click "Looking To Travel" → Edit → "My New Title"

### To Change Images
1. Find the image area
2. Paste a new image URL
3. Click upload or confirm
4. Image updates instantly

**Example**: Change `/dubai-image.jpg` → `/my-image.jpg`

### To Add Items
1. Click the [➕ Add] button
2. New item appears with defaults
3. Edit the fields
4. Done!

**Example**: Click "➕ Add Team Member" → Fill details → Appears in list

### To Delete Items
1. Click the [🗑] trash icon
2. Item removes instantly
3. You can undo with Ctrl+Z

**Example**: Click trash on unwanted package → It's gone → Ctrl+Z to restore

---

## Step 4: Use Controls

### Undo (Ctrl+Z)
- Made a mistake? Press Ctrl+Z
- Goes back one change
- Can press multiple times

### Redo (Ctrl+Y)
- Changed your mind about the undo?
- Press Ctrl+Y to restore
- Can press multiple times

### Reset Button
- Want to start fresh?
- Click "Reset" in the header
- Goes back to original defaults

### Export Button
- Save a backup of your content
- Click "⬇ Export"
- JSON file downloads
- Keep it safe!

### Import Button
- Restore from a backup
- Click "⬆ Import"
- Select your JSON file
- Everything restored

---

## Step 5: View Live Preview

### On Desktop
- Right side shows live preview
- Changes appear in real-time
- Shows how it looks on your site

### On Mobile
- Click the 👁 button (floating on screen)
- Toggle between edit and preview
- See changes instantly

## Common Tasks (Copy & Paste Ready)

### Edit Hero Title (Home Page)
1. Go to **Home** tab
2. Find "Title:" field
3. Click text
4. Change to your text
5. Press Enter

### Add New Package
1. Go to **Packages** tab
2. Click **[➕ Add Package]**
3. Fill in:
   - Name: Your package name
   - Price: 999
   - Duration: 5 Days
   - Category: travel/study/work
4. Click expand to add details

### Edit Team Member
1. Go to **About** tab
2. Find team member card
3. Click expand button (▼)
4. Edit name, role, bio
5. Upload new photo
6. Done!

### Change Service Description
1. Go to **Services** tab
2. Pick service (Study, Work, etc.)
3. Edit title or description
4. Changes save automatically

### Backup Everything
1. Click **[⬇ Export]** in header
2. Save the JSON file
3. Keep in safe place
4. Can restore anytime

## Troubleshooting

### Q: Changes aren't showing?
**A:** Make sure you clicked Save (✅ button) or pressed Enter

### Q: Lost my changes?
**A:** Press Ctrl+Z to undo, or click Undo button

### Q: Image won't appear?
**A:** Try pasting image URL with full path: `/images/filename.jpg`

### Q: Forgot what I changed?
**A:** Click Reset to go back to original, then make changes again

### Q: Want to save my work?
**A:** Click Export button, download JSON file, keep safe
