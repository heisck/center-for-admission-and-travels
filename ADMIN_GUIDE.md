# Admin Dashboard Guide

Welcome to the Center for Admission and Travels Admin Panel. This comprehensive system allows you to manage and edit all content on your website in real-time with a professional, intuitive interface.

## Overview

The admin panel is a replica of your main website, with every element made editable. You can modify text, images, packages, team members, and more without any technical knowledge.

## Key Features

### 1. **Editable Content Sections**

The admin dashboard provides four main editing areas:

- **Home** - Edit hero section, services, statistics
- **About** - Manage mission, vision, core values, team members
- **Packages** - Create and edit travel packages with details
- **Services** - Manage service offerings and descriptions

### 2. **Undo & Redo**

- Every change is tracked automatically
- Use the **Undo** button (↶) to revert last change
- Use the **Redo** button (↷) to restore changes
- Navigate through your complete edit history

### 3. **Real-Time Preview**

- On desktop/tablet: See live preview of your changes in the right panel
- On mobile: Toggle preview with the floating eye icon
- Changes update instantly as you make them

### 4. **Image Management**

- Upload images by pasting URLs
- Manage multiple images per section
- Preview images before saving
- Remove images individually
- Support for JPG, PNG, GIF, WebP formats

### 5. **Data Export & Import**

- **Export**: Download all your content as a JSON file for backup
- **Import**: Load previously saved content from JSON files
- Keep backups of different versions

## How to Edit Content

### Editing Text

1. Click on any text to enter edit mode
2. Edit the content directly
3. Press **Enter** to save (or **Escape** to cancel)
4. For longer content, use the textarea - press **Ctrl+Enter** to save

### Managing Lists

- Click the **+** button to add new items
- Click the **trash icon** to delete items
- Edit fields inline or in the form

### Adding Images

1. Navigate to the image section
2. Click "**Add Image**" button
3. Paste the image URL
4. Preview appears below
5. Click "**Add Image**" to confirm
6. Remove images with the remove button

### Managing Packages

1. Go to **Packages** tab
2. Click a package to expand details
3. Edit all fields (name, price, duration, highlights, etc.)
4. Add highlights or included items with the **+** button
5. Click delete to remove entire package
6. Add new packages with **Add Package** button

### Managing Team Members

1. Go to **About** tab
2. Scroll to **Team Members** section
3. Click to expand and edit member details
4. Update name, role, image URL, and bio
5. Add new members with **Add Member** button

## Tips & Tricks

### Keyboard Shortcuts
- **Ctrl+Z** - Undo
- **Ctrl+Y** - Redo
- **Escape** - Cancel editing

### Best Practices
- Save regularly by exporting your data
- Use clear, concise descriptions
- Ensure image URLs are valid before adding
- Test changes on the preview
- Keep consistent naming and formatting

### Data Backup
- Export your content weekly
- Store backups in a safe location
- Use versioned filenames (e.g., `content-2024-01-15.json`)

## Important Notes

⚠️ **Local Storage**: All changes are stored in your browser. If you clear browser data, changes will be lost.

📱 **Responsive Design**: The preview shows how content appears on different devices.

🔄 **Reset**: The Reset button reverts all changes to defaults. Use with caution - this cannot be undone.

💾 **Persistence**: To save changes permanently, export the JSON file and save it securely.

## Troubleshooting

### Images Not Loading
- Check that image URL is valid and accessible
- Ensure URL includes full protocol (https://)
- Try a different image format or source

### Changes Not Saved
- Ensure you've clicked Save/Confirm button
- Check that browser hasn't been closed
- Export your content as backup

### Preview Not Showing
- On mobile, click the eye icon to toggle preview
- On desktop, ensure window is wide enough for split view
- Try refreshing the page

## Support
