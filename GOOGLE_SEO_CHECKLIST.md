# Google visibility checklist — CA Travels (CFAAT)

Technical work on the website is only half of local SEO. Google also needs off-site signals.

## Done on the website (code)

- [x] `en-GH` language + `hreflang` (`en-GH`, `en`, `x-default`)
- [x] Canonical URLs per page
- [x] TravelAgency + Organization + ProfessionalService JSON-LD
- [x] `areaServed`: Ghana + West Africa
- [x] Geo coordinates (from admin contact or Accra fallback)
- [x] Opening hours in schema
- [x] NAP in footer (Name, Address, Phone) with Ghana
- [x] Service/landing pages: `/ghana`, `/study-abroad-ghana`, `/travel-abroad-ghana`
- [x] FAQ schema on key pages
- [x] Sitemap includes local landing pages
- [x] robots.txt allows major AI crawlers

## You must do in Google (off-site) — critical for “near me” / Ghana results

1. **Google Business Profile (GBP)**  
   - Claim/verify: https://business.google.com  
   - Business name must match site NAP: *Center for Admission and Travels*  
   - Primary category: e.g. Travel Agency  
   - Secondary: Education consultant / Visa consultant if accurate  
   - Service areas: Accra, Greater Accra, Ghana (+ other cities you serve)  
   - Website: https://catravels.com  
   - Same phone and address as the website footer  

2. **Google Search Console**  
   - Add property for https://catravels.com  
   - Submit sitemap: `https://catravels.com/sitemap.xml`  
   - Set geographic target is **not** available for all domain types; `en-GH` + local content is your signal  

3. **Rich Results Test**  
   - https://search.google.com/test/rich-results  
   - Test homepage for TravelAgency / Local business markup  

4. **Citations (same NAP everywhere)**  
   - Facebook, Instagram, LinkedIn, directories  
   - Name / address / phone must match the website exactly  

5. **Reviews**  
   - Real Google reviews mentioning study abroad / travel packages  

6. **Content**  
   - Publish blog posts answering real Ghana queries (e.g. “study in UK from Ghana documents”, “Dubai tour cost from Accra”)  

## How Google decides (honest expectations)

When someone in Ghana types **“study abroad”** or **“travel abroad”**, Google ranks pages by:

1. **Relevance** — does the page clearly match the query for users in that market?  
2. **Proximity** (for local-intent queries) — distance to the business + service area  
3. **Prominence** — links, reviews, brand mentions, GBP engagement  

The website cannot force placement. Strong local schema + Ghana landing pages + GBP + reviews is what professional agencies do.
